Password Strength Checker
A beginner-friendly Python project that checks password strength using basic security rules.

Features

- Checks password length (minimum 8 characters)
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Displays Weak, Medium, or Strong feedback
- Provides tips to improve password strength

Technologies Used

- Python 3
- getpass module
- string module

How to Run

1. Install Python 3.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run:
   
   python main.py
